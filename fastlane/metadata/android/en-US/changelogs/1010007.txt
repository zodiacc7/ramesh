Ramesh 1.1.0.07 (build 1010007) — pre-release.

The action strip now matches the picture icon for icon: a filled bin with a separate lid, a solid disc for message details, a check with two rules for Select, the share glyph with its arrowhead, and a filled arrow sweeping up from the bottom left for Forward.

Typing:
- The composer follows the language you type. Persian (and Persian mixed with English) reads right to left, English left to right, so the caret, the placeholder and the first word all start on the correct side.

Fixes:
- "Mark all as read" now clears spam too. Spam is stored read from the moment it arrives, so the button used to leave the spam badges counting messages that no longer had any unread partners.
- Opening a conversation no longer sends you back to the first row when you come back. The list keeps its position per tab and only jumps to the top when you actually switch tabs.
- The copy highlight is visible on every bubble now: it is derived from the bubble's own text colour, so it no longer disappears on the accent-coloured bubbles.

New:
- Send delay shows the message as a pending bubble in the conversation, with a countdown and a Cancel button underneath it. Cancelling puts the text straight back in the composer.
- "Auto-delete spam" in Settings, off by default: pick a number of days, and filtered spam older than that is removed in the background.
- Filter Studio has a Decisions tab that lists every number you marked spam, silent or blocked, with a search box and a Restore button, so a number silenced by mistake can be found and freed again.
- Settings now offers "Share the last crash log" whenever the app closed unexpectedly, so the reason for a crash can be reported instead of guessed.
- Leaving the app is more defensive around the inbox receiver, which is a crash that had no visible cause.

Dates are untouched in this build.

This is a pre-release: it is published with the `--prerelease` flag and is not the "latest" release.
