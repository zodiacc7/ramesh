Ramesh 1.1.0 (build 1101) — pre-release, updated build.

The message menu is now a horizontal bar, the way Textra does it:
- One tap on a bubble shows a single strip: Copy · React · Share · Forward · Delete · Info · Mark as read. Nothing hides behind a "More" submenu, and the strip sits over the top of the chat so the message it acts on stays readable.
- Hold a message to select it, as before; full-text selection also lives in the long-press "Message options" dialog, so you can still copy just a part of a long message.
- A verification code in the message appears as a chip on the left of the strip; one tap copies the code itself, not the whole message.
- Report spam was removed from the menu. Iranian operators publish different report numbers, so the action had no dependable target; a wrong report is worse than none.
- Forward still shows your recent conversations and sends the original text as a normal SMS.

Fixed — dates in every tab and list:
- The date formatters used to be built once, with the phone's own language, instead of the language chosen inside Ramesh. On an English phone running the Persian UI they produced English weekday and month names.
- It looked random because the list picks a different pattern per row age: time for today, weekday for this week, full date beyond. A single list could show `۱۹:۳۳` next to `Sep 14`, and which rows disagreed depended on how old each message was — which is why the tabs seemed to use different formats.
- Formatting is now built per app language (Persian → fa-IR, English → en, System default → the phone), so chat, inbox, tabs and search results all print dates the same way, and switching the language repaints them immediately.

This is a pre-release: it is published with the `--prerelease` flag and is not the "latest" release.

Full feature list and install/verification instructions: github.com/zodiacc7/ramesh
