Ramesh 1.1.0 (build 1101) — pre-release. Tap a message to do something with it.

What is new:
- Tap a message bubble to open a small menu: Copy, Forward and More. Holding a message still selects it, exactly as before.
- More holds Share, React, Info, Select and Report spam. Share sends the text to any other app; Report spam sends it to your operator's report number, which you enter once and can change later (there is no universal number, so Ramesh never guesses one).
- The message text inside the menu is selectable, so you can copy just a part of a long message.
- Links, phone numbers and dates inside that menu are tappable: a link opens in the browser, a number in the dialer, and a date switches the calendar.
- A verification code in the message appears as a chip at the top of the menu; one tap copies the code itself, not the whole message.
- Forward shows your recent conversations and sends the original text as a normal SMS.

Fixed — dates no longer disagree between tabs:
- The conversation list only honoured the "Jalali everywhere" setting, while the chat screen also followed the calendar switch you get by tapping a date. The same inbox could therefore show Shamsi dates in one place and Gregorian ones in another. Both now use one rule.
- With the language set to "System default" on a Persian phone, the list formatted dates as English (Latin digits, "Shahrivar 23"); it now follows the device language like the rest of the app.
- Search results were formatted with the device locale instead of the app language, so they could mix Latin and Persian digits.

This is a pre-release: it is published with the `--prerelease` flag and is not the "latest" release.

Full feature list and install/verification instructions: github.com/zodiacc7/ramesh
