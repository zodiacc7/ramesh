Ramesh 1.1.0.05 (build 1010005) — pre-release.

The action strip behaves like the picture:
- The first strip button is Select: it opens selection mode with that very message selected. The old read/unread toggle is gone — the double check now sits in the selection bar, where it marks the whole conversation read.
- The strip slides in and out on every message: received ones slide left to right, sent ones right to left, mirrored as you would expect in the Persian right-to-left layout. It no longer fades on one side and slides on the other.
- Copy no longer opens any window. It copies the message, closes the strip and turns the bubble itself into selectable text with the whole message selected, so you can adjust the selection and copy only the part you want.
- The strip carries a label on Copy and icon-only actions elsewhere, mirroring the reference.

The selection bar is redesigned:
- Close, mark-as-read, "N selected", share, forward, delete, and one overflow menu holding copy, message details (single selection) and select all.
- Quick-reaction emojis are gone from the top bar; reactions live in the strip on the message, which is where you use them.

New spam is identifiable:
- A conversation with spam you have not opened yet gets a solid shield chip ("Spam 1") instead of a faint outline, plus a bolder row title. The badge number and the row now agree at a glance.
- The filtered spam message itself is marked with a "New" badge next to "filtered spam", so opening a thread tells you which message arrived.

Message details shows "Delivered" only for messages you sent; an incoming message no longer claims a delivery time it cannot have.

Dates are untouched in this build.

This is a pre-release: it is published with the `--prerelease` flag and is not the "latest" release.
